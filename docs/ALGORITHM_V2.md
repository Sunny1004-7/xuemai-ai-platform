# 学习证据与任务调度

知识状态采用 Beta 加权证据模型，初始参数 α=1、β=3。距上次有效证据 d 天时，证据保留比例为 2^(-d/30)，α、β 中超出先验的部分按这一比例折减。状态值为 α/(α+β)，同时返回有效证据量、近似区间与证据充分度。区间采用 Beta 方差的正态近似，供界面表达不确定性。

题目难度 1/2/3 对应基础权重 1/1.4/1.8。独立正确的质量为 1；使用 h 条提示后正确，质量为 1/(1+h)；错误质量为 0。更新为 α←α+wq，β←β+w(1−q)。同题24小时内重试权重降为35%，此前正确且本次再次正确的权重为0，且不刷新知识状态的证据时间。主观题等待教师复核后才更新。旧版掌握记录以两条弱证据迁入，历史作答保留。

有效证据少于2时显示“待补充证据”，2至6之间显示“证据积累中”，达到6显示“证据较充分”。这些是小样本演示课程的设计参数，需要在后续教学中标定。

复习调度借鉴 SuperMemo SM-2：独立正确质量5、提示正确质量3、错误质量1；首次与第二次成功间隔为1和6天，之后乘难易因子，难易因子最低1.3。错误回到1天，有提示时最长2天。重复成功保留原调度，避免短时间重做推迟复习。

推荐综合当前状态、未订正错题、复习到期与个人目标，再沿先修DAG查找低于45%的前置知识。任务序列包含先修知识、知识卡或视频片段、针对性练习、辅导理解检查和间隔复测。没有可评分练习的知识点不生成空转练习入口。

教师发布任务时保存各目标学生的知识状态和有效证据基线。结果页分开展示任务完成、发布时与当前状态、增加的有效证据。这个对照帮助教师跟踪后续表现；教育效果需要更长周期的对照研究。

数学性质测试使用固定时间验证提示差异、时间折减、重复权重、复习间隔等；接口场景在隔离合成数据库中验证先修路径、错因、理解检查和任务前后对照。没有使用真实学生数据估计预测准确率。
