# 本次公开开发证据筛选快照

`index.html` 是本机只读回放页，支持知识图谱、练习作业、AI 辅导三个主题，以及原话搜索与类型筛选。可直接在浏览器打开，不请求外部服务。

`visible-records.json` 保存去重后的公开记录；三个 `*-chain.json` 是主题筛选副本，文件名中的 chain 只表示主题组织，不表示已经取得完整原始 Prompt 链。`manifest.json` 记录四个指定来源文件名、筛选范围、缺口、记录数量及产物哈希。来源行号便于在本机核验。

## 筛选边界

- 用户消息：保留原始用户发言和界面答复，排除宿主环境与打开页面的上下文。
- 助手消息：只保留 commentary、final/final_answer 中的公开文本。
- 协作：只处理 spawn_agent、send_message、followup_task 的公开参数与非空回执，以及实际收到的公开 input_text 正文。
- 测试：只保留实际测试命令与退出码，不导出终端原始输出。
- 系统、开发者消息、内部非公开内容、加密块、无关工具结果及其他会话均排除。字段未获白名单许可时，不访问或导出其内容。

本次存储中的协作参数正文和多数接收 Payload 为加密内容。导出器不解密，也不把空外壳或密文串冒充 Prompt。相应记录只显示“协作元数据（正文缺失）”。因此该自动快照不能单独满足三个完整 Prompt 链的要求。

如主代理提供 `004-核心功能实际协作逐字转存.md`，回放页会增加独立入口。该附录从本聊天可见协作卡片逐字转存，来源与自动导出分别标明；它不等同完整原始聊天导出，建议另保留原始界面截图或录屏核验。

## 复现

```powershell
.venv/Scripts/python.exe scripts/export_development_evidence.py --self-test
.venv/Scripts/python.exe scripts/export_development_evidence.py
```

默认只查找代码中明确列出的本次四个会话文件，不自动遍历其他聊天。可通过 `--sessions-dir` 指定这四个文件所在的本机目录。导出时移除凭据、一次性认证码、个人邮箱与本机绝对路径，扫描产物后才写入。

导出是截至 `manifest.json` 时间的快照，仍在进行的会话之后可能新增公开记录。更新时重跑脚本，保留真实时间和来源，不补写缺失的历史发言。
