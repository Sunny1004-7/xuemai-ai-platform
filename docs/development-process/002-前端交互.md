## 迭代与验证
1. 读取后端真实 `docs/API_CONTRACT.md`，按课程、知识点、资源、作业的共享标识实现页面；AI 子代理补充 SSE meta/delta/done/error 与生成草稿契约。
2. 首轮 `npm run build` 失败：TypeScript noUnusedLocals 捕获 16 个未使用 import/参数。移除真实错误后重新执行构建通过，没有关闭类型检查。
3. 实际发生一次 npm 工作目录误选，在根目录生成仅含开发依赖的 package/lock；核对内容后删除误建文件，重新在 frontend 安装，保留根 node_modules 为忽略的可删除缓存。没有触碰用户资料。
4. AI 子代理审查提示真实模式为 `real` 而非 `live`，并指出缺失 done 的 SSE EOF 和停止生成不应表现为完整回答。前端修正模式标识，强制收到 done 才视为结束，历史 `interrupted` 显示未完成，输入限制对齐 3000 字。
5. 后端契约审查提示 `lesson_plan` / `true_false` / 难度 1–3 / `pending_review`。逐一修正；多选答案转数组，资源编辑保留原 metadata，视频上下文携带 resource_id。
6. 私有视频不能直接由 video 标签携带 Bearer，改为鉴权读取 Blob 后使用 object URL，并在切换或卸载时撤销 URL。预置公开教学视频仍直接播放。
7. 主代理首轮 E2E：视频定位、播放、笔记持久化与学生窄屏通过；教师流程在开发热更新时出现 Context 身份变化白屏，主代理改为生产 preview 验证，避免一边开发一边 HMR 干扰测试（生产不使用 HMR）。
8. 自主补充个人目标/学习计划真实 CRUD、推荐转计划；教师题目审核/编辑/复制版本；知识学习目标；前端截图审查后将关键正文提高至 13px、辅助标签保持 11–12px，取消外链字体保证离线可用。
