# 学脉教学方法验证

## 复算入口

运行 `python scripts/run_round10_experiments.py --offline` 重算知识追踪、路径与班级实验。运行 `python scripts/round10_retrieval.py` 构造隔离课程并重算检索。运行 `python scripts/build_round10_report_data.py` 从已经完成的逐例结果生成统计、图形及报告数字，材料构建过程只读取结果。

真实模型实验需要显式执行 `python scripts/round10_live.py --real`。协议、任务和结果保存在本目录，已完成的结果直接读取。业务场景入口为 `python scripts/round10_end_to_end.py --real`。两者共用同一预算数据库和范围，总额上限1,000,000 Token。历史用量继续保留在原记录中。

## 固定的比较与评分方法

随机种子101711。算法参数沿用正式业务实现。K-TRACE开发120条、评测1200条，生成器采用带难度、猜测、失误、提示与随机状态变化的逻辑函数，另有突变和无遗忘条件。生成规则与Beta更新公式不同，均方根误差按每条轨迹计算后取平均，六种生成条件同时保留。零权重事件沿用持久参数，时间查询仅形成当前预测。

PATH-G开发20图、评测180图，图规模6、9、16、24、32节点，关系密度0.06、0.16、0.28，随机移除8%的候选资源。每图10、20、30、60分钟四种预算，共720个评测场景。可行贪心采用相同效用、候选、先修与预算，每步选择边际效用密度最高的合法活动。静态目标排序保留为无顺序控制参照。小图使用子集动态规划求精确参考。置信区间按独立图聚类重采样，保留同图预算结果的相关性。重规划重新调用正式算法并保留改变后的状态和序列。

CLASS-LOOP开发6班、评测48班，16—80人，覆盖原型、噪声、缺失、稀疏、混合与结构变化。明确单一原型时比较成对关系一致率，混合场景检查成员覆盖、输入重排、观察组与任务匹配。对照包括去支持度以及总困难程度四分位分组，所有方法使用相同学生。成对关系一致率计算所有学生对的同组判断，结果同时保留具体成员与任务。

检索200问按50个知识主题分组，同一主题的四种问法进入同一分区，开发20问、评测180问。三个课程使用实际FTS索引与普通上传附件，参考来源在执行排序前由对应讲义与私有附件固定。评价定义为参考文档或附件在前k名出现的比例及首次出现名次倒数。精确段落定位另行检查。权限六例和证据不足一例单列，不加入180问分母。该集合主要检查课程内定位、无知识上下文及附件联合检索，专门的FIFO/LIFO比较与否定沿用既有独立回归。

## 真实模型配对

12次试运行单列，随后冻结80个独立任务，学生、教师各40个，分别覆盖八类意图。每任务两种提示条件，顺序按任务摘要确定。双方使用相同模型、课程资料、诊断原始字段、班级统计、动作与题目候选、JSON样例、输出长度、权限检查及后处理，仅简化提示中的教学编排措辞。这个较强基线用于观察编排提示在共享业务工具条件下的增量，原始证据和受控执行带来的共同收益由端到端验证判断。

以独立程序核查API完成、结构合法、来源定位、引用编号、持久记录、草稿保存。学生结构要求存在有效理解检查，教师产物任务要求形成有效草稿，讨论和分析允许正常回答。业务完成要求API完成、相应结构有效、记录落库，教案与干预方案还需保存成功。引用定位与编号单列，句子支持使用已有词项检查并保留原文供复核。评分不按回答长度计分，未采用模型自评作为主要证据。各类任务分别列出分子与分母。

模型参数及具体任务见 `protocol.json`，Flash为主要模型，Pro用于有代表性的复杂子集，温度0.3、关闭思考模式。学生最多700、教师最多1200输出Token。官方模型版本与计价来源保留在协议。官方usage中的缓存输入继续计入输入，推理明细已经包含于输出时仅保留明细。费用按官方峰值价估计上界，实际扣费由官方结算。

## 失败与恢复

零自动重试，失败结果保留。缺少官方usage时按完整预留计入控制额。在途预留包含于剩余额度计算。数据库写锁负责跨进程累加，完成结算幂等，脚本恢复优先读取已完成结果。断点中存在未知状态时保留其预算，相关任务需核对既存记录后再处理。

原始结果包含合成教学数据及其模型解释，公开记录无密钥、认证头或真实个人教学资料。教学效果研究与本次工程、模型任务评价分别理解，正文中的数值对应这些已定义的验证条件。
