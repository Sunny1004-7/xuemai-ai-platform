回放页由 scripts/export_development_evidence.py 构建，默认打开 docs/development-process/raw-evidence/index.html。自动快照只保留本次指定会话中的公开字段，不读取加密正文。另有004逐字转存文件，从本聊天可见工具卡片转存三条核心链，明确这是Codex自主分工，不能称为用户逐条追问。

本片展示已发生过程的回放，不冒充实时代码生成。原始自动导出对协作正文存在缺口，建议参赛前仍保留 Codex 原界面卡片截图作为交叉核验材料。三个核心功能Prompt链由逐字转存、测试、实际提交和回放共同提供证据，不能把自动元数据本身当成完整原始聊天。

重新录制先安装 scripts/requirements-tools.txt 中的可选工具依赖，启动Mock后端与5175生产预览，执行 frontend/scripts/record-demo.mjs、scripts/narrate_demo.ps1 和 scripts/assemble_demo_audio.py。录制会真实发布一个合成作业、提交练习与笔记，应使用演示数据库。DEMO_QUICK=1仅进行约12秒预演，不导出正式MP4。原始逐帧截图和时间戳位于被忽略的.local/recording，最终媒体位于“最终参赛提交材料”。
