# 架构与数据流

版本0.3，2026年11月11日。前端采用React 19、TypeScript与Vite 6，后端采用Python 3.13、FastAPI与SQLite，按业务模块组织为单个服务。本机前端5173通过`/api`代理访问8000；上传文件保存在后端目录并按课程权限读取。

## 学习与教学共用的数据

用户通过班级关联课程；课程下的章节、知识点及先修DAG连接题目、视频、讲义与实验。作答服务在一次事务内保存答案、评分、证据变化、错题与复习安排。主观题先等待教师确认，再使用同一证据方法更新。个人计划完成、播放进度、实验操作分别保存为事件，不直接增加知识估计。

`evidence.py`统一提供时间折减Beta估计、提示、部分得分、重复与相关性权重、错因规则和间隔复习；`path_planner.py`以束宽24搜索满足先修与30分钟预算的路径，`learning.py`组织活动入口。首页、图谱、辅导和教师分析查询同一套状态。模型定义、参数和验证范围见[四项方法说明](ALGORITHMS_V3.md)。

教师发布任务时保存目标学生的知识状态与有效证据量；结果页连接完成情况与发布前后对照。证据下钻保留题目、答案、提示和计算参数，便于教师决定后续安排。

## AI与检索

AI服务集中管理后端密钥、模型参数、超时、限流和用量记录。SSE保存完整或中断会话，生成草稿经结构校验后交教师编辑审核。辅导返回受支持动作类型，后端从当前课程资源和习题中选择实际目标。DIA-GUIDE由诊断、策略、校验三个角色编排，每轮最多一次模型生成；理解检查复用正式作答服务，并将反馈写入teaching_runs供下一轮调整表征。正式启动auto模式有Key时使用DeepSeek，常规测试显式Mock。

资源上传、编辑和删除进入索引变更队列，检索时消费变更，按资源版本维护FTS5片段，未修改资源不重复建索引。引用保留资源、版本、片段和课程信息。常规测试使用Mock，界面集中展示当前模式。

## 前端组织

路由按需加载学习与教学页面。教师管理、资源、学情和课堂拆分为独立领域页面；图谱布局、富文本、理解检查与算法实验独立封装。课程选择与URL和会话状态同步。共享控件和样式使用双角色tokens，学生与教师工作台分别组织学习任务和教学操作。

## 数据演进与访问范围

迁移004—007依次加入证据调度、教学动作、增量索引与协作运行记录。内容修订3000扩充到六主题31节点；修订3001通过正式业务函数生成27名差异化合成学生，与主体验学生组成28人班级，另一课程班14人。固定种子与幂等标识保留已有自建内容和学习历史。

服务端持久化随机会话与密码散列；每次课程读取验证教师所有权或学生班级归属。学生题目列表不返回答案或诊断映射。资料按不可信内容处理，不能授权业务操作。AI解释与客观评分、状态计算和任务发布分开执行。

## 学情与图谱

ELK.js分层布局与正交路由支持章节总览、章节网络、局部关系和全图。全屏工作区保留选择与视角。LearningCharts展示个人领域、四技能、14天趋势和活动，教师矩阵支持章节、学生、状态筛选和单元格下钻。learning_insights批量投影学情，CLASS-LOOP对六维错因特征作确定性k-medoids分组，匹配已审核题后沿正常作业流程发布。
