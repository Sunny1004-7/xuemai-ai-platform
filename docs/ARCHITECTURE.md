# 架构与边界

客户端：React/TypeScript/Vite，浏览器仅请求 /api，由 Vite 代理到 127.0.0.1:8000。
服务端：FastAPI 模块化单体；SQLite 外键、事务、版本迁移与课程范围授权；本地资源目录。
实体：用户→班级成员→课程→章节→知识点（先修 DAG）→资源/题目；作业→提交→学习事件→掌握度→推荐→分层任务。
AI：独立服务层，服务端环境变量、结构化校验、SSE、限流、超时与用量账本；Mock 与真实模式可见且分离。

认证使用服务端持久化随机会话与密码散列；任何课程内容先校验教师所有权或学生班级归属。学生接口不得暴露题目答案。
AI 资料为不可信上下文，只能辅助解释，不得触发权限变更、执行代码或跨课程检索。
推荐使用可解释的确定性算法，AI 不更改客观评分。
