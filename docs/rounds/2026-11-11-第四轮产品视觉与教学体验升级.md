## 业务与方法改进

学生首页优先呈现下一项学习任务，切课程同步推荐、活动和任务；练习返回知识估计的前后状态及证据权重，并重算后续路径。教师学情采用知识矩阵、教学干预、学生轨迹、作答复核四工作区，切换后保留筛选。趋势图无作答日期不画假正确率。

PATH-G修正缺少可执行先修资源时的尾部放行问题。CLASS-LOOP增加六维证据支持度和低证据观察组，群组焦点按支持度计算，未观测维度不成为错因。定义与实现见[四方法说明](../ALGORITHMS_V4.md)。

固定种子4011的机制实验：K-TRACE完成27组消融并验证重复成功权重为0；PATH-G的12图×4预算共48例先修和预算违规0，静态目标排序出现36个先修违规步骤；CLASS-LOOP的24名等均分、四类错因合成学生纯度1.0，对照0.333333，组内加权距离0.01410282，对照1.19527882；DIA-GUIDE五类策略匹配5/5，固定提示1/5，两轮Mock接口完成检查失败后的策略切换。28人隔离班1847条评分，以5次SELECT生成快照，单次39.2毫秒。结果用于验证机制与业务衔接。

## 实际问题与修正

1. 旧手机图谱样式使用130%宽和负边距，造成画布偏移；清理覆盖并重新截图。
2. 固定最小缩放不能同时满足全图容纳与阅读；拆分全图适配与115%聚焦阅读，保存全屏前相机并恢复。
3. PATH-G候选尾部可能绕过缺失先修资源；保持阻塞条件并增加验证。
4. 分层时缺失技能证据曾参与错因距离；增加支持度与观察组，并验证重排稳定和证据变化。
5. 视频开发回放卡片与路径实验画板出现溢出；调整字号、行距和局部间距，再逐画板检查。
6. Git HTTPS推送遇到连接重置；采用官方Git数据接口传送原始对象，逐项核对SHA、作者与时间，再非强制快进。
