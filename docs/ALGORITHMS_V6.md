# 第六轮知识网络与双角色协作方法

K-TRACE、PATH-G和CLASS-LOOP沿用[第五轮定义与验证](ALGORITHMS_V5.md)，本轮保留评分、目标预算、分层及任务回流。下面给出新增机制、实际实现入口和验证范围。

## DIA-TEACH 教学目标与班级证据双约束编排

输入为教师问题、课程、可选班级和当前对象。任务规划识别教学讨论、分析、设计、分层干预、出题和量规建议。讨论读取授权资料。班级分析读取当前教师有权管理的课程与班级，专题问题进一步限定知识范围。工具调用复用学情投影与CLASS-LOOP，返回错因、知识状态、群组、候选题和已有任务。

设方案为 $D=(S,G)$，教学预算为 $B$，合法候选题为 $Q$。校验同时要求

$$\sum_{s\in S}t_s\le B,\quad Q_j\subseteq Q,\quad group_j\in G_{authorized}.$$

群组学生由服务端补入，统计数字与工具返回证据核对。模型只执行一次解释与草稿生成。教案、题目和任务分别进入现有编辑与确认入口。保存教案使用唯一请求键防止重复写入，发布作业仍由教师审核班级、学生和习题。

实现位于 `backend/app/teacher_assistant.py`、`ai_routes.py` 与 `frontend/src/components/TeacherDraft.tsx`。Mock与真实测试均覆盖轻量讨论、专题统计、分层教学、编辑保存和任务审核。真实Pro复测中栈队列统计限定到对应知识范围，验证通过。题目生成、教案生成与量规建议各有官方端到端调用记录。

## DIA-GUIDE 学习意图与课程对象约束

原有诊断、策略、校验共享状态增加概念解释、辨析、程序过程、例题、练习、复习和一般讨论意图。程序过程优先进入受控实验。对象解析先核对用户给出的题目、资源和知识，再匹配课程中有正式注册的实验别名。

队列对应队列实验，栈对应栈实验。视频片段必须属于当前知识且时间点有效。没有明确对象时保留普通辅导，理解检查仍使用实际作答回写。正式注册表由正常初始化建立，重启和升级保持幂等。

实现位于 `teaching_actions.py`、`teaching_agents.py`、`activity_catalog.py`。测试包含队列映射、跨课程资源拒绝、理解检查反馈和持久会话恢复。

## 知识关联片段联合检索

课程资料与当前会话私有附件共同参与候选检索。文本按标题和段落切分，每片段最多800字符，保存页码、段落或行号。排序采用

$$R(c,q)=L(c,q)+0.5I_{current}+0.2I_{neighbor}.$$

$L$是词项重合得分，两个指示量表达当前知识与邻接知识关联。每文档最多2段，总计最多5段、5200字符。引用保存原片段、定位和版本。权限在每次查询中检查，未缓存跨身份结果。

20个固定候选的同词歧义案例中，词项排序Top-1和Top-3均命中1/20，知识关联排序均命中20/20，全部定位有效。这组对照只说明受控歧义条件下知识上下文的作用。查询、候选和预期标识均在[验证脚本](../scripts/verify_round6_methods.py)内，结果见[对照记录](rounds/第六轮检索方法对照.json)。

## 稳定知识网络与空白通道路由

节点按标识排序，使用章节柔性锚点、连接力、斥力和57单位碰撞半径，固定420次迭代。编辑已有节点时，以原位置75%和章节锚点25%作为初始吸引中心，减少布局变化。默认图由真实课程数据计算。

连线先在多种弯曲幅度与控制点比例中寻找二次曲线。仍有遮挡时，以26单位网格、8邻域A*搜索空白通道，线段与其他节点保持56单位间距，再压缩可见路径并对拐点做9单位圆滑处理。节点拖动和画布平移分别处理。

实际27、31节点课程及合成6、31、80节点均无节点碰撞、连线遮挡，重排输入保持布局一致。四种画布尺寸的节点可见和锚点误差检查通过，最大压力例本机总验证约623毫秒。实现为 `frontend/src/graph-layout.ts`，结果见[几何验证](rounds/第六轮知识网络几何验证.json)。

## 模型、附件和语音执行

Flash与Pro按请求构造配置，消息记录实际模型、模式与官方用量。Flash处理图片，Pro处理文本。附件校验上传者、课程与会话，删除时撤销索引及文件。语音使用本地Whisper small，录音结束释放设备，临时音频处理后删除。转写文本可以修改，固定学科同音词订正保留原结果。

真实联调共13次，Flash 10次、Pro 3次，输入16527、输出2540 Tokens，全部成功、无自动重试。原子账本将包括失败在内的全部真实网络请求计入本轮20次上限，后续常规回归、截图及录制使用Mock。详见[真实联调记录](rounds/第六轮DeepSeek真实联调.json)与[语音核验](rounds/第六轮本地语音核验.json)。
