# 学脉设计系统

## 设计方向
学习平台的辨识度来自「知识之间的脉络」，不是装饰性数据大屏。学生首页聚焦下一次学习行动，教师首页聚焦具体教学干预。知识图谱作为学习路径的真实索引，所有入口连接数据库实体。

初案审视：通用 SaaS 的四张统计卡不能说明学生下一步做什么，因此首页改用「继续学习 + 解释性路线」为主视觉，统计仅作次要信息。

## 视觉变量
- 墨蓝 #18243e：稳定的导航与文字。
- 学脉青 #168675：学习路径、已掌握与主要行动。
- 课程蓝 #4568d8：课程与知识网络。
- 纸白 #f5f7fb：工作区；白色 #ffffff：内容层。
- 琥珀 #bf7b2e：待复习，文字同时说明状态。
- 字体优先系统中文 Microsoft YaHei / PingFang SC，拉丁数字 Aptos / Segoe UI。
- 大标题 28–32px，页面标题 26px，正文 14–15px，最小辅助文字 12px。

## 布局
桌面 216px 深色导航 + 弹性主工作区；内容最大宽 1440px。首页主列 2:1，侧列呈现学习任务；课程工作区视频和字幕并排。850px 以下导航缩成图标列，620px 以下内容单列。

所有文本左对齐；数值比较使用一致的基线。圆角按层级分为 8px 控件、12px 内容区、18px 主学习区；避免层层同形卡片。

## 交互
键盘焦点清晰，表单 label 关联；禁用重复提交。加载、空态、保存成功与失败均可感知。图谱可拖拽平移、滚轮/按钮缩放、键盘选择节点；播放进度、笔记、作答和实验事件持久化。AI 明示 Mock/真实服务状态，不伪造模型结果。
动效服务状态变化，尊重 prefers-reduced-motion。统计从接口读取，不将合成演示数据伪装成真实学生。
