# 学脉设计系统

版本0.2。学生界面围绕下一项学习任务、当前课程和具体作答组织，教师界面围绕课程操作、学习困难、评阅与任务发布组织。两端共用排版、控件、间距和焦点规则，分别使用宋瓷青绿与茶烟米褐主题。完整原色与token映射、对比度和前后截图见[配色规范](DESIGN_TOKENS.md)。

学生五色为#2E6A67、#5E8C87、#A9C8BE、#D7E6DB、#F1F0E8；教师五色为#7E6554、#A78A73、#D4B79D、#E9D6BE、#F5EEE4。背景与图形层次使用浅色，正文和浅色柱条数值使用深墨色。浅色不承担小字，状态同时用轮廓、文字和图标表达。标题采用宋体衬线，正文使用系统无衬线字体。

导航和列表优先表达信息层级。练习把题干与作答放在中心，视频把播放器与时间线相邻，辅导以对话、引用和可执行动作为主，教师学情把证据与教学行动相邻。删除不承担操作或信息作用的副标题与口号，保留必要的错误、保存、权限、加载及AI模式状态。

图谱按六个主题自动布局，节点为圆形与环形状态，连线表达先修方向。首次自动适配，搜索、缩放、拖动、邻居与先修聚焦支持从全网进入具体知识。桌面和390px手机采用不同工作区排列；长列表与弹窗可以滚动，焦点和按钮可通过键盘识别。

当前验证覆盖四种视口、20模块与336张截图。八组关键颜色组合均达到普通文字4.5对比度要求。手机全网较小，可使用搜索、聚焦与缩放查看。整站交互仍应结合实际课程使用持续调整。
